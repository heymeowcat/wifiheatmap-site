# WifiHeatmap Website

Official product website and landing page for **WifiHeatmap** — the Android Wi-Fi analyzer and indoor site survey tool.

## 🚀 Built With

- **Astro v5** (Static Site Generator)
- **Tailwind CSS v4** (Modern utility-first styling)
- **React 19 & Framer Motion** (Interactive mobile simulator showcase)
- **Lucide Icons**

## 🧞 Commands

| Command | Action |
| :--- | :--- |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Builds static site to `./dist/` |
| `npm run preview` | Previews production build locally |

## 📄 Pages Included

- **Home (`/`)**: High-impact hero, interactive 4-tab animated mobile phone showcase, architectural feature cards, FAQ, and store CTAs.
- **Privacy Policy (`/privacy-policy`)**: Detailed offline transparency policy, Android permissions breakdown (`ACCESS_FINE_LOCATION`, `ACTIVITY_RECOGNITION`).
- **Terms of Service (`/terms-of-service`)**: User agreement and software terms.
